# Birthday Surprise 🎂

Jalankan: `npm install && npm run dev` lalu buka http://localhost:3000

Personalisasi semuanya di `lib/config.ts` (nama, pesan, alasan, surat, foto, musik).
Foto: taruh di `public/photos/` lalu isi `src` (mis. "/photos/1.jpg").
Musik: taruh `public/music.mp3` lalu isi `music: "/music.mp3"`.
Deploy gratis: push ke GitHub lalu import ke vercel.com.
